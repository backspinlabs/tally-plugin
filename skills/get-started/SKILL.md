# Get started with Tally

Tally reads a shop's Lightspeed Retail (R-Series) data from a copy it refreshes every few minutes and answers questions about sales, stock, service, customers, and the team.

1. Call `shop_overview` once. Say which open stores Tally sees, when the data last synced, and how far back sales history goes (its `coverage`). Never guess a store's name; use the ones it returns.
2. Say in one line what this person's account can see. If cost, customer, or team figures are off for them, say the shop owner can turn them on in Tally's Settings.
3. Offer three questions to try, picked to fit what they can see:
   - "How did we do yesterday?"
   - "What stock should we clear?"
   - "Which jobs are waiting on parts?"
4. Ask whether there is anything the shop always wants handled a certain way: which payment types count as money at the end of day, which category they watch most, or which purchases need a service follow-up. When they answer, save it with `remember` so Tally uses it next time.

Keep it short. Don't list every tool.
